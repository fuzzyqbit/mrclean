Transaction algorithm (persistAllocations, inside withMapLock — pin this exactly):
1. key = await ensureSessionKey(baseDir, sid)  // wx create-once INSIDE the lock — closes the key-before-map window
2. map = await readSessionMapFile(baseDir, sid) ?? createEmptySessionMap(sid)  // authoritative re-read under lock
3. for each pending IN ORDER: hmac = hmacAddress(map.hashSalt, p.value)  // ALWAYS recompute with authoritative salt
   - hit in map.entries => final = existing.placeholder (foreign/prior allocation wins — never burn a counter)
   - miss => map.counter + 1 => final = formatV2Token(p.type, counter, map.nonce8); insert makeMapEntry(p.type, final, counter, p.value) (secret floor applies structurally)
   - final !== p.provisionalPlaceholder => push { from: provisional, to: final }
4. await writeSessionMapFile(baseDir, sid, newMap, key)  // fresh IV, wfa fsync:false — map mtime refresh IS the TTL heartbeat (D-07)
5. return renames
Immutability: build newMap/entries as new objects; never mutate the map read from disk.
