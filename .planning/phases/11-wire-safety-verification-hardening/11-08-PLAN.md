<objective>
Fix the SC1b live wire-safety gate's absence assertion so it measures the actual
wire-transmitted surface instead of every byte under `~/.claude/projects`, and
correct the phase's own documentation of what that gate proves.

Root cause (`.planning/debug/sc1b-resume-canary-leak.md`, diagnosed 2026-07-18):
the reported "blocker" (both run-unique canaries found in the resumed session's
transcript) is **not a product leak**. mrclean's real hook redacted correctly in
both runs; the canonical wire-mirrored record (`type:"user"`, `tool_result`) was
clean in both. The raw canary bytes were found in a `hook_success` **attachment**
on an adjacent transcript line — Claude Code's local-only bookkeeping for a
DIFFERENT hook (the operator's globally-installed `ecc` plugin's
`session-activity-tracker.js`, scope:`user`, matcher `*`), which echoes its own
raw pre-redaction stdin to stdout. Claude Code archives every hook's raw stdout
into the session transcript as a `hook_success` attachment regardless of which
hook produced it — this is the SAME parallel-hook-fan-out mechanism
`docs/HOOK-CONTRACT.md` already documents for the test's own fixture observer,
just triggered here by a hook mrclean has no relationship to.

`grepProjectsTreeForCanaries` (tests/uat/wire-safety.test.ts:372-398) does a raw
whole-file byte grep across every jsonl record/attachment type instead of
scoping to the wire-mirrored surface. This plan narrows that scope, adds
regression + non-vacuity fixture tests proving the narrowing is correct (not
just permissive), opportunistically hardens the harness against the ambient
plugin in the future (OAuth-safe, best-effort), and corrects the two docs that
conflated the wire and the local transcript tree as the same surface.

Purpose: eliminate a false-positive "blocker" in the phase's own verification
gate without weakening its actual security guarantee (real leaks still fail
hard), and make the gate's documented claim match what it actually checks.

Output: corrected `tests/uat/wire-safety.test.ts` + `tests/uat/harness.ts`,
corrected `.planning/ROADMAP.md` SC1 wording, corrected
`docs/HOOK-CONTRACT.md` Evidence section.
</objective>
