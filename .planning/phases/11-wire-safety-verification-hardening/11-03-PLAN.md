<feature>
  <name>Cross-session collision demote-to-unmatched in the restore union index</name>
  <files>src/restore/session-index.ts, tests/restore/session-index.test.ts</files>
  <behavior>
    Given the union build iterates entries across multiple decrypted session maps:
    - Case A (collision): sid1 map carries placeholder P with original O1; sid2 map carries the SAME P with original O2 (O1 != O2) => P is in NEITHER placeholders nor any restorable structure; a document containing P restores with P byte-unchanged (unmatched). Non-vacuity FIRST: assert sessions === 2 (both maps really decrypted) before any absence assertion.
    - Case B (sticky demotion): three maps carry P with O1, then O2 (demote fires), then O1 again => P still absent from the index (a bare delete would let the third occurrence re-set it — the sticky Set is load-bearing). sessions === 3 asserted first.
    - Case C (benign duplicate): sid1 and sid2 both carry P with the SAME original O1 => placeholders.get(P) === O1 (idempotent re-set is not a collision; restores normally).
    - Case D (regression): every pre-existing row — OVF exclusion, poisoned-map, secretPlaceholders membership, corrupt-map skip, session filter, no-write proof — green unchanged.
    Fixture recipe: forced identical placeholders REQUIRE hand-built map JSON (formatV2Token embeds per-map nonce8, so serializer-built maps cannot collide) — build a valid SessionMapV1 object literal with explicit placeholder strings, JSON.stringify, encryptMapBuffer(Buffer.from(json), await ensureSessionKey(base, sid), sid), write envelope bytes to mapPathFor(base, sid) with mkdir sessionsDir mode 0o700 and file mode 0o600 (the 10-02 poisoned-map recipe already in this test file).
  </behavior>
  <implementation>
    In the union-build loop (current line ~150 bare set): declare `const demoted = new Set<string>()` alongside the placeholders accumulator (function scope — spans ALL maps in the union, not per-map). Per entry, before setting: skip if demoted.has(entry.placeholder); read existing = placeholders.get(entry.placeholder); if existing !== undefined && existing !== entry.original => placeholders.delete(entry.placeholder), demoted.add(entry.placeholder), continue; else placeholders.set(entry.placeholder, entry.original). No new imports; no signature change; file stays read-only fs surface. Local Map/Set construction inside the builder is the established pattern (fresh structures per call — no shared-state mutation).
  </implementation>
</feature>
