<feature>
  <name>Policy-filtered restore index over the encrypted session store</name>
  <files>src/restore/session-index.ts, tests/restore/session-index.test.ts</files>
  <behavior>
    Discovery: readdir(statePaths(baseDir).sessionsDir); consider ONLY names ending '.map' whose stem passes SESSION_ID_RE (janitor sidFromName discipline). readdir ENOENT => empty RestoreIndex. With sessionFilter: if !isValidSessionId(filter) => empty RestoreIndex, zero paths derived; else consider only that sid.
    Per candidate: readSessionMapFile(baseDir, sid) — null => skip silently (not counted in sessions). For each entry of a decrypted map: isRestorableType(type) && 'original' in entry && placeholder does not contain ':OVF:' => placeholders.set(placeholder, original); entries failing isRestorableType => secretPlaceholders.add(placeholder); restorable-typed OVF placeholders => in NEITHER structure (engine short-circuits them by label).

    Fixture recipe (real ciphertext — never synthetic JSON on disk): tmp baseDir per test; ensureSessionKey + writeSessionMapFile persist maps built from createEmptySessionMap + makeMapEntry + formatV2Token + hmacAddress (chaos.test.ts buildSeedMap shape).
    Cases:
    - sid1 map { WORD w/ original, PII_EMAIL w/ original, AWS_KEY (secret), WORD@counter-1000 (OVF) } + sid2 map { WORD w/ original } => union: placeholders has 3 pairs (sid1 WORD + sid1 PII_EMAIL + sid2 WORD); secretPlaceholders has exactly the AWS_KEY placeholder; OVF token in neither; sessions === 2
    - sessionFilter = sid1 => only sid1 pairs; sessions === 1
    - sessionFilter = '../../etc/passwd' (and 'mcp-server') => empty index, no throw — even when valid maps exist on disk
    - corrupt map: flip one ciphertext byte at offset 37 (magic 8 + version 1 + IV 12 + tag 16 — chaos.test.ts CT_OFFSET recipe) => that sid skipped; other sessions still indexed; sessions counts only decryptable maps
    - non-conforming filenames planted in sessionsDir ('README.txt', 'evil..map', '&lt;sid&gt;.map.bak') => invisible
    - absent sessionsDir (fresh tmp baseDir, nothing written) => { placeholders: empty, secretPlaceholders: empty, sessions: 0 }
    - hand-poisoned map: build a VALID SessionMapV1 JSON by hand where the AWS_KEY entry carries original: 'zz-poisoned-secret-original' (JSON.stringify of an object literal — bypassing serializeSessionMap which would strip it), encrypt via encryptMapBuffer(Buffer.from(json), await ensureSessionKey(base, sid), sid), write the envelope bytes directly to mapPathFor(base, sid) => index contains NO value equal to 'zz-poisoned-secret-original' anywhere (parse-time drop + read-side gate, defense in depth)
    - no-write proof (Pitfall 7): capture readdir listing + per-file mtimeMs of sessionsDir and keysDir before buildRestoreIndex; assert both byte-identical after
  </behavior>
