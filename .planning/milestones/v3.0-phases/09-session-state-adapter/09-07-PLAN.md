Handler flow to implement (both handlers, mirrored):
1. AFTER config load + session-state bootstrap, BEFORE detection:
   if (config.reversible.enabled) { try { lazy-import facade; if (isValidSessionId(sid)) { h = await readSessionMapForHydration({sessionId: sid}); if (h) { hydrateSessionManager(sid, h); mark reversible-active } } } catch { /* one-way fallback */ } }
2. Detection/substitution runs UNCHANGED (steps and emitted variables identical to today).
3. On the BLOCK/deny (budget) and dry_run return paths: if reversible-active, drainSessionAllocations(sid) and DISCARD (nothing emitted => nothing to persist; dry_run substitutes nothing => a persisted entry would be an orphan).
4. On the findings>0 emit path: pending = drainSessionAllocations(sid); if pending.length > 0 => r = await persistAllocations({ sessionId: sid, pending, deadlineMs: POST_LOCK_DEADLINE_MS }); if (r.status === 'ok' && r.renames.length > 0) apply renames — applyRenamesDeep(updatedToolInput, r.renames) for PreToolUse, applyRenamesToText(result.substitutedText, r.renames) for PostToolUse — BEFORE building the response object. Degraded/noop => emit as-is (provisional tokens stand, facade already warned once).
5. No-findings path: nothing drained needed (no allocations occur without findings) — leave untouched.
```
