<objective>
Fix CR-01: the three-layer config merge silently disables operator-enabled protections when a higher-precedence layer contains a partial `[pii]`/`[pii.*]` or `[reversible]` table. Root cause: validators bake `DEFAULT_CONFIG` values into parsed layers, so a TOML layer is never a true Partial and mergeConfigs' last-wins replaces lower-layer opt-ins with defaults.

Purpose: This is a protection-semantics failure in a DLP tool — the exact failure class mrclean exists to prevent (proven by execution during review and verification: user `[reversible] enabled = true` + project `[reversible] future_key = 1` merges to `enabled = false`; user PII opt-ins including SSN/credit-card BLOCK actions are silently disabled by a project file that only narrows `[pii.regex].entities`). Phase 9 consumes `reversible.enabled` directly; this must be fixed before it is consumed.

Output: Parsed layers are true Partials (absent fields stay absent); default-filling lives ONLY in mergeConfigs (fill from the accumulated value, never the bundled default mid-merge); cross-layer TOML tests prove the documented forward-compat scenario preserves operator opt-ins.

TDD feature: cross-layer partial-table config merge — defined I/O (TOML layers in, merged MrcleanConfig out).
</objective>

```typescript
/** Parsed-TOML layer shape for [pii.regex]. Absent field == "this layer does not set it". */
export interface MrcleanPiiRegexConfigLayer {
  enabled?: boolean
  entities?: string[]
  actions?: Record<string, PiiAction>
}

/** Parsed-TOML layer shape for [pii.ner]. Absent field == "this layer does not set it". */
export interface MrcleanPiiNerConfigLayer {
  enabled?: boolean
  model?: string
  dtype?: string
  entities?: string[]
  confidence?: number
  allowDownload?: boolean
  warmOnBoot?: boolean
  actions?: Record<string, PiiAction>
}

/** Parsed-TOML layer shape for [pii]. */
export interface MrcleanPiiConfigLayer {
  enabled?: boolean
  regex?: MrcleanPiiRegexConfigLayer
  ner?: MrcleanPiiNerConfigLayer
}

/** Parsed-TOML layer shape for [reversible]. */
export interface MrcleanReversibleConfigLayer {
  enabled?: boolean
}

/** One parsed config layer. Replaces Partial<MrcleanConfig> as the layer currency:
 *  pii/reversible sub-tables are themselves partial-shaped, which Partial<MrcleanConfig>
 *  cannot express (its pii? is a FULL MrcleanPiiConfig). */
export interface MrcleanConfigLayer {
  dry_run?: boolean
  allowlist?: MrcleanAllowlist
  entropy?: MrcleanEntropyConfig
  secrets_files?: string[]
  rules?: MrcleanRuleOverride[]
  pii?: MrcleanPiiConfigLayer
  reversible?: MrcleanReversibleConfigLayer
}
```
